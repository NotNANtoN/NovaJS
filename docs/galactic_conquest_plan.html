NovaJS — Galactic Conquest & Multiplayer Realms Plan

Architectural blueprint for Mode 2 (Storyless Faction Conquest), Spaceport Bar Bounty Board, and Multi-Realm Server Isolation.

Mode 1: Story & Co-op Wings (Live) Mode 2: Galactic Conquest (Planned) Mode 3: Freelancer Sandbox & Bounty Board

1. Vision & Realm Architecture

EV Nova combines rich single-player NCB storylines with a systemic sandbox of 6 major factions, planetary defense fleets, territory borders, and trade routes. By partitioning rooms by Game Mode / Realm on the Start Menu (story, sandbox, conquest), a single NovaJS server or cluster can host both purist co-op campaigns and persistent faction warfare without NCB bit collisions.

Mode 1: Story & Co-op Universe (story)

Full retail EV Nova storylines. Players can hail each other (`Y`) to Form a Wing, automatically route into the same system variant on jump, and share combat mission kills & payouts when fighting in the same system.

Mode 2: Galactic Conquest (conquest)

Storyline NCB locks disabled. Players pledge to a major faction (Federation, Auroran, Polaris, Rebel, Pirate, Vell-os) and fight alongside NPCs and wingmates to dominate planets and flip system ownership on the live starmap.

Mode 3: Freelancer Sandbox (sandbox)

Open galaxy without storyline gating, featuring dynamic Spaceport Bar player/NPC bounty boards, piracy, trading, and escort rescues.

2. Galactic Conquest Mode — Core Mechanics

2.1 Faction Allegiance & Starting Loadouts

  • When creating or entering a pilot in conquest mode, the player chooses one of the primary factions:
    • Federation (Sol / Earth, gövt 128)
    • Auroran Empire ( Aurora, gövt 129)
    • Polaris (Polarisin, gövt 131)
    • Rebellion (New Ireland / Rebel space, gövt 133)
    • Pirate Clans / Associated Guild (gövt 130 / 135)
  • All non-story shipyards and outfitters are unlocked based on Faction Rank / Conquest Points and credits rather than story NCB bits.
  • Base canonical systems are used everywhere (no hidden storyline duplicate systems).

2.2 Shared Planetary Domination & Territory Flipping

In single-player EV Nova, demanding tribute from a planet spawns its spöb defense fleet and records domination only in the local pilot's dominatedStellars. In Galactic Conquest, planetary ownership is stored in an authoritative server-side ConquestWorldState: 

interface PlanetConquestState {
    planetId: string;           // e.g. "nova:128" (Earth)
    systemId: string;           // e.g. "nova:128" (Sol)
    controllingGovt: number;    // Current owning gövt ID
    capturedByWing?: string;    // Wing/Clan or pilot names that captured it
    captureTimestamp: number;
    fortificationLevel: number; // 1..3 (scales defense fleet waves)
}
  • Co-op Planetary Sieges: Multiple players in a Wing can hail an enemy planet (`Y`) and initiate a siege together.
  • Capture & Flip: When the planet's defense fleet is defeated, controllingGovt flips to the attackers' faction. If all inhabited stellars in a system are held by one faction, the system's effective government flips!
  • Live Starmap Territory Borders: nova/src/spaceport/territory_field.ts already computes territory influence fields from each system's government color. Feeding the live ConquestWorldState overrides into territory_field.ts makes the starmap borders shift in real time for every connected player!
  • War Chest & Tribute: Controlled planets pay daily tribute split among online faction members and unlock that planet's tech tier for friendly pilots.

2.3 Dynamic Frontline War Missions

Instead of static mïsn story chains, the Mission BBS and Spaceport Bar in Conquest Mode generate dynamic frontline missions on border systems (systems with a hyperjump link to a rival faction's system):

Mission Type Objective Conquest Effect
Frontline Strike Destroy 4–8 enemy patrol ships in an adjacent rival system Weakens target planet's fortificationLevel before a siege
War Supply Convoy Deliver 30 tons of munitions/medical supplies to a contested planet Increases friendly planet's fortificationLevel and restocks shipyard
Fleet Interception Intercept an NPC invasion task force en route to a friendly system Prevents automatic NPC territory flip and awards high faction rank points

3. Spaceport Bar Bounty Board & Co-op Rescue

  • Live Bounty Board in Spaceport Bar (nova/src/spaceport/bar.ts):
    • Tracks pilots (and notorious `përs` raiders) who have accumulated negative legal records or destroyed friendly ships.
    • Players can view the last known star system of wanted targets and accept a bounty contract.
    • Disabling or destroying a wanted target in-system awards the posted bounty from the server combat ledger.
  • Distress Beacons & Crippled Friend Rescue:
    • Already supported by assistance_plugin.ts (boarding/assisting a disabled player repairs hull and transfers jump fuel so they can fly again).
    • Wingmates see a highlighted WING DISTRESS indicator in their HUD chat feed and starmap when a wingmate is disabled, making co-op rescue missions natural and immediate.

4. Implementation Roadmap

Phase 1 — Done Start Menu Mode Switcher & Co-op Wings: Selectable mode on the Start Menu, in-flight Wing formation via Player Hail (`Y`), friendly green Wing brackets, same-system variant jump routing, and shared combat mission goals.

Phase 2 Realm Room Prefixing & Conquest World Store: Namespace MultiRoom system channels by mode (conquest:nova:128 vs story:nova:128) and add nova/src/server/conquest_store.ts for persistent planetary ownership.

Phase 3 Planetary Siege & Live Starmap Territory Broadcast: Broadcast ConquestWorldState diffs to clients so starmap.ts and territory_field.ts render live faction borders.

Phase 4 Frontline War Mission Generator & Bar Bounty Board: Add procedural border-war missions in procedural_missions.ts and the Bounty Board dialog in bar.ts.
